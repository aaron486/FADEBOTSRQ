# Vacation AI

A Tinder-like vacation discovery app that shows influencer posts, flight deals, and activities for dream destinations.

## Features

- **Swipe to Discover** - Tinder-style swipeable cards with destination photos, influencer posts, flight deals, and activities
- **Explore** - Browse all destinations with search and tag filtering, trending section
- **Saved Trips** - View and manage destinations you've saved
- **Profile** - Track your travel style, savings, and preferences

## Tech Stack

- React 19 + Vite
- Framer Motion (swipe gestures & animations)
- React Router (navigation)
- Lucide React (icons)

## Getting Started

```bash
cd vacation-ai
npm install
npm run dev
```

Open http://localhost:5173 in your browser.
